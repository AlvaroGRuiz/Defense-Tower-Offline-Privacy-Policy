# Privacy Policy — Tower Defense Offline (english)

**Last updated:** 20 October 2026

**Developer:** lynxsp 
**Contact:** alvarogruiz8@gmail.com
**App:** Tower Defense Offline

## Overview

Tower Defense Offline is an offline single-player game. It does not require an internet connection to play and does not include advertisements or in-app purchases in the current version.

## Information we collect

The app stores data **only on your device**, for example:

- Language and audio preferences
- Game speed preference
- Run save / continue data
- Lifetime statistics
- Discovered relics codex progress

This information is not uploaded to our servers because the game does not use a backend for gameplay.

## Permissions

The app does not require special device permissions beyond what is needed to install and run a standard Unity Android game. It does not request access to your contacts, camera, microphone, location, or files outside the app’s own storage.

## Third-party services

The current release does not integrate advertising SDKs, analytics SDKs, crash-reporting cloud services, or social logins.

If a future update adds such services, this policy will be updated before those features ship.

## Children’s privacy

The game is a general-audience strategy game. We do not knowingly collect personal information from children. Because gameplay data stays on the device and is not transmitted by us, there is no personal data collection for online profiles.

## Data deletion

You can clear app data from your device settings (Android → Apps → Tower Defense Offline → Storage → Clear data), or uninstall the app. That removes local saves, stats, and preferences stored by the app.

## Changes to this policy

We may update this policy when the app changes. The “Last updated” date at the top will change when we do.

## Contact

Questions about this policy: alvarogruiz8@gmail.com

# Política de privacidad — Tower Defense Offline (español)

**Última actualización:** 20 de octubre de 2026

**Desarrollador:** lynxsp  
**Contacto:** alvarogruiz8@gmail.com  
**Aplicación:** Tower Defense Offline

### Resumen

Tower Defense Offline es un juego para un jugador que funciona sin conexión. No incluye anuncios ni compras dentro de la aplicación en la versión actual.

### Datos que se guardan

La app guarda información **solo en tu dispositivo**, por ejemplo:

- Idioma y opciones de audio
- Preferencia de velocidad de juego
- Partida guardada / continuar
- Estadísticas
- Progreso del códice de objetos descubiertos

Esos datos no se envían a nuestros servidores porque el juego no usa un backend de partida.

### Permisos

No pedimos acceso a contactos, cámara, micrófono, ubicación ni archivos fuera del almacenamiento propio de la app.

### Servicios de terceros

Esta versión no integra SDKs de anuncios, analítica, reportes de fallos en la nube ni inicio de sesión social.

### Eliminación de datos

Puedes borrar los datos de la app en Ajustes de Android o desinstalarla.
